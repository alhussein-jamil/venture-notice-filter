Problems this tests

  • A filename such as soft-hold-enrollment should not be mistaken for an rm -r option.
  • git checkout --detach is not the same as destructive checkout flags.
  • A command quoted in documentation or a heredoc is not necessarily executed.

These behaviors were raised in hook false-positive report #28 and hook regression report #96.
