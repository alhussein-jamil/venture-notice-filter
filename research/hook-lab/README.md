# Hook Regression Lab — commercial hypothesis test

Free public, client-side tester for Claude Code `PreToolUse` Bash regex rules.

- Web URL: https://alhussein-jamil.github.io/venture-notice-filter/research/hook-lab/
- This is **not** an automated dangerous-command blocker, sandbox, or security assurance.
- All user commands remain in-browser; the app has no external dependencies, analytics endpoint, cookies, or checkout.
- A request for a future CLI version is counted only when an actual GitHub issue is submitted by a separate account. Merely opening the link is not a conversion, and a feature request is not willingness to pay.
- Evidence: https://github.com/disler/claude-code-hooks-mastery/issues/28 and https://github.com/Adam077K/agentvibe/issues/96; an open bounty at https://github.com/claude-builders-bounty/claude-builders-bounty/issues/3 advertises $100 for a guard, but authenticity, competition, and payment are unverified.
- Differentiation hypothesis: inspect false positives *before* installing risky hook code and export a reproducible test report.
- Competing tools exist. This experiment does not assert market share, buyers, or revenue.
- Test: `cd research/hook-lab && node --test tests/test.mjs` (Node 20+).
- Next objective evidence: at least **three distinct non-owner, non-bot, substantive issues** requesting a specific improvement, during a 30-day observation window. Counts are observational and do not prove payment intent.
- Stop or rethink if no qualified interest appears after a documented distribution test. Publishing alone does not imply any impressions.

Existing BOAMP product at the repository root remains unchanged.
